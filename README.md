## 🧠 O que foi praticado

- **HTML semântico e acessível:** `header`, `main`, `section`, `fieldset`/`legend`, `label` ligado via `for`, `aria-describedby` e `role="alert"`
- **Formulários com validação nativa:** `required`, `pattern`, `min`/`max` e feedback visual com `:valid`, `:invalid` e `:focus`
- **Responsividade mobile-first:** media queries em `min-width`, imagens de fundo e logos diferentes por breakpoint
- **Layout com Flexbox e CSS Grid**
- **CSS organizado:** variáveis em `:root`, reset próprio, arquivos por seção unidos com `@import` e nomenclatura **BEM**
- **Menus sem JavaScript:** hambúrguer e dropdown com `checkbox` + `label` e o seletor `:checked ~`
- **JavaScript no navegador:** manipulação do DOM, delegação de eventos com `data-action`, eventos customizados, `setInterval` e a API `Audio`
